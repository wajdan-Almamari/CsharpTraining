# Banking Services System

A console-based Banking Services System developed using C#.

## Description

This project simulates a banking system that allows users to manage account information, perform ATM operations, validate PINs, calculate transactions, print receipts, and access various banking services through a menu-driven console application.

## Features

### System Setup

* Create account information
* Store customer details
* Configure transaction data
* Manage account settings

### ATM Services

* Bank information
* View account data
* PIN validation
* Receipt printing

### Account Management

* Transaction calculator
* Account type information
* Loan eligibility preparation

### Banking Operations

* Deposit calculations
* Withdrawal calculations
* Interest calculations
* Balance analysis

### Receipt System

* Short receipt
* Detailed receipt
* Balance-only receipt

## Technologies Used

* C#
* .NET Console Application
