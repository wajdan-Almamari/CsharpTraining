# Clinic Management System (CMS)

A console-based Clinic Management System developed using C#.

## Description

This project simulates a clinic management system that allows users to manage patients, doctors, and appointments through a menu-driven console application.

The system supports patient registration, doctor management, appointment booking, appointment tracking, and record maintenance.

## Features

### Patient Management

* Add new patients
* Display all patients
* Update patient phone numbers
* Delete patient records

### Doctor Management

* Add new doctors
* Display all doctors
* Update consultation fees
* Delete doctor records

### Appointment Management

* Book appointments
* Display appointments
* Update appointment status
* Cancel appointments
* Prevent duplicate appointments

### Validation Features

* Patient age validation
* Empty field validation
* Consultation fee validation
* Capacity limits for patients, doctors, and appointments
